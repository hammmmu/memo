# 打勾備忘錄

分類待辦清單，未完成的任務可以加進 iPhone 內建「行事曆」提醒。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 整個 App（畫面、功能、資料都在這） |
| `manifest.webmanifest` | 讓「加入主畫面」後像一般 App 一樣全螢幕開啟 |
| `sw.js` | 沒網路也能打開 |
| `icon-*.png` | 主畫面圖示 |

## 放上 GitHub Pages（免費）

1. 到 github.com 註冊並登入。
2. 右上角 **＋ › New repository**，名稱例如 `memo`，選 **Public**，按 **Create repository**。
3. 在新的 repository 頁面按 **uploading an existing file**，把這個資料夾裡的所有檔案拖進去（不用拖 README 也可以），按 **Commit changes**。
4. 到 **Settings › Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 **Save**。
5. 等一兩分鐘，網址會是 `https://你的帳號.github.io/memo/`。

> Public repository 代表程式碼任何人都看得到，但你的任務**不會**上傳，只存在手機裡。

## 裝到 iPhone

1. 用 **Safari** 打開上面的網址（一定要 Safari）。
2. 按下方 **分享** 按鈕 › **加入主畫面**。
3. 之後從主畫面圖示打開。

## 使用

- **右滑任務**：星號（排到最上面）、延遲（選 1 小時後／今晚／明天／週末／下週一／自己選）、刪除（可以按「復原」）。
- **加到行事曆**：按任務右邊的日曆圖示 › 跳出「加入行事曆」› 按 **加入**。提醒時間在編輯任務時設定。
- **改了時間或延遲之後**：行事曆裡的舊活動不會自己跟著改，要再加一次，然後去行事曆刪掉舊的。
- **子項目**：新增或編輯任務時可以加子項目（例如「去全聯」底下放衛生紙、青菜、醬油），卡片右邊的「0/3」點開就能直接打勾。
- **計畫**：後製、讀書、學習、其他都放這裡。每個計畫有進度 %、剩幾天、每天要做多少、已投入幾小時。可以自己加階段（後製：粗剪、調色、字幕；讀書：第 1 章、寫考古題…），每個階段一條 0–100% 的拉桿，總進度取平均。「安排工作」會在行事曆加兩個活動：工作時段，和結束時的「回報進度」提醒。回來後在後製頁按「回報」更新 %。
- **前置**：劇組或案子的倒數天數，以及「要帶的器材／要精進的／要準備的」三份清單。「帶入常用器材」一鍵加入你的固定器材。拍完按「拍完了，建立後製案子」。
- **備份**：「我的 › 匯出」存成 .json，換手機時用「匯入」還原。

## 之後要改

改完檔案重新上傳到 GitHub，並把 `sw.js` 第一行的 `memo-v1` 改成 `memo-v2`（每次加 1），手機才會抓到新版。
